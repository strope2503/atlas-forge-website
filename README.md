# Atlas Forge Website v1.0

A responsive, static marketing website for Atlas Forge and its product ecosystem:

- Scout Pro
- Atlas Media
- THRF™

## Preview locally
Open `index.html` in a browser. For the most accurate local preview, run:

```bash
python -m http.server 8000
```

and visit `http://localhost:8000`.

## Publish
See [DEPLOYMENT.md](DEPLOYMENT.md) for GitHub Pages instructions.

## Brand assets
Vector logo files are stored in `assets/brand/`.

## Current limitations
The early-access and contact forms are visual prototypes and are not connected to an email service or database.
